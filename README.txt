طريقة التشغيل (مرة واحدة، وتعيدها كل ما تعدّل حاجة في src):
1) نزّل Python من python.org لو مش عندك، وبعدين في الترمنال:  pip install cryptography
2) افتح الترمنال جوه الفولدر ده وشغّل:  python build.py
3) اكتب الإيميل والباسورد (نفس الاتنين دايمًا، وإلا بياناتك القديمة مش هتتفتح).
4) هيتعمل فولدر dist. امسح كل ملفات الموقع القديمة من الريبو وارفع محتوى dist بدلها.
تحذير: فولدر src فيه الصفحات غير مشفّرة. متترفعوش على GitHub أبدًا. واحتفظ بملف build.salt جنب build.py.
